# openfold3-accel

Drop-in, reversible inference acceleration for [OpenFold3](https://github.com/aqlaboratory/openfold-3),
aimed at multicore CPUs.

```python
import openfold3_accel  # patches apply on import (set OPENFOLD3_ACCEL_DISABLE=1 to opt out)
```
